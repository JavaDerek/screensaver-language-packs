# Spanish pack source

This directory is the data-only source for the official Spanish pack.
`pack.json` declares its lists, language, version, attribution and license files.
See the source README files under `data/` for the original source methods,
limitations, pinned revisions and licenses. Paths in historical source READMEs
refer to the original application layout; the repository root README describes
building this separated pack directory.

Build release archives with `scripts/build_catalog.py` from the repository root.
